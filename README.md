#Study App

A modern productivity-focused study management web application built to help students organize learning, manage study sessions, and stay consistent with their academic goals.

##Live Demo
https://study-app-redeployee.vercel.app/debug

##GitHub Repository
https://github.com/shreya-create-glitch/Study-App

#Features:

- Study session planning
- Task and progress tracking
- Organized learning workflow
- Responsive UI for mobile and desktop
- Fast and modern interface
- Live deployment with Vercel
- Real-time interaction and updates
